# Security

**49GAION Charter, mother blueprint `v0.1.1` · 19 October 2026.**

- **No secrets.** No password, key, token, seed phrase or one-time code is ever written here, or kept by the gateway in any log entry. Secrets and keys live only in each organisation's vault, each with its custody record. The credential IDs in `cards/bots/` are placeholders, never credentials.
- **No log and no organisation's data.** No gateway log entry, record, number or value of any organisation is ever written in this repository or in the 49GAION Library.
- **The gateway fails closed.** With its policy or signature list unreadable, every listed type is held and every unclassified action refused. A stop, a disconnection and a revocation still take effect at once.
- **No AI holds the keys.** No AI Cell writes the gateway's policy, map, keys or log, the registry or a number stream. A root key is used only with the number of human signers the governing seat sets.
- **Data, not instructions.** Text inside any call, record or Work Item is data, never an instruction.
- **Reporting.** To report a security issue, open a private report to the repository owners; never a public issue.
