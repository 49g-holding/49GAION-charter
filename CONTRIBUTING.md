# Contributing

**49GAION Charter, mother blueprint `v0.1.1` · 19 October 2026.**

1. **One change, one pull request.** It is reviewed by someone other than its writer, and merged by the governing seat of 49GAION.
2. **No organisation's data.** Never write here an organisation's name, host, code, document, value, key, log entry or record (Naming Standard R9).
3. **No tool names.** Tools are named by role only; product names appear only in an organisation's own copy (Protocol §10, item 5; §23, item 11).
4. **Positions, never people.** No person's name, initials or personal ID in any file.
5. **No AI holds the keys.** A change that would give an AI Cell write rights to the gateway's policy, keys or log, the registry or a number stream is refused (Protocol §23, item 7).
6. **Cite every rule** to its source: a 49GAION text by section and version. Never invent a fact, a version, a score or an appointment. `NOT_RUN` is never PASS.
7. **The blueprint governs the cards.** Edit the card data block of blueprint §17 only, then run `python3 tools/make_cards.py <49GAION-protocol/spec/schemas>`. It must report 0 errors.
8. **Decided texts are never edited.** A change is a new version that names what it supersedes. A decision record never changes once merged.
9. **A new version reaches the Library** only by a pull request to `49GAION-protocol` that moves the pin.
10. **English only, plain and short.**
